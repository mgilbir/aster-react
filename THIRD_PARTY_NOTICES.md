# Third-party notices

`@aster/core`, `@aster/react` and `@aster/vl` have no runtime dependency on any
`vega-*`, `d3-*` or `topojson-*` package (`pnpm check:deps` enforces that on the
sources and on the built `dist`). They do, however, contain TypeScript ports and
transcriptions of those projects' algorithms, tables and colour palettes, and
they are verified against the real packages as test oracles. Each project whose
code or data the sources port, transcribe or reproduce is listed below with the
version that was ported (the version pinned in this repository's lockfile), and
its licence text is reproduced verbatim, copied from the `LICENSE` file shipped
in that package. Where several projects carry byte-identical text it is printed
once, above the list of projects it covers.

`scripts/notices.test.mjs` checks, on every `pnpm test`, that each text below
is byte-for-byte the `LICENSE` file of every project listed under it.
